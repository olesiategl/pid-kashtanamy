# Під каштанами

Два односторінкові сайти-пропозиції (Здолбунів, вул. Василя Жука):

- `susid/` — для сусіда
- `rada/` — для міської ради

Кожна папка — готовий статичний сайт (`index.html` + `img/`). На Netlify: окремий сайт для кожної папки, Base directory = `susid` або `rada`, без команди збірки.
